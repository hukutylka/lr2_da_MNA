# API-пайплайн для анализа отзывов на Диснейленды

## Описание проекта
Проект реализует API-пайплайн для автоматического анализа текстовых отзывов о парках Disneyland.
Скрипт выполняет следующий процесс:
```text
CSV-файл с отзывами -> Gemini API -> структурированный JSON-результат
```
На вход подается CSV-файл с отзывами. Каждый отзыв отправляется в языковую модель через Gemini API. Модель анализирует текст и возвращает структурированный результат в формате JSON.
Для каждого отзыва определяется:
- тональность отзыва: `positive`, `negative`, `neutral`;
- основная тема отзыва;
- краткое содержание на русском языке;
- ключевые слова;
- уверенность модели от 0 до 1.

## Используемая модель
В проекте используется модель Google Gemini 2.5-flash-lite.
Модель получает текстовые отзывы и возвращает ответ по заранее заданной JSON-схеме. Это позволяет получить не обычный текст, а структурированные данные, пригодные для дальнейшего анализа.

## Описание входных данных
Входной файл расположен в папке `data`:
```text
data/DisneylandReviews.csv
```
Описание столбцов:
| Поле | Описание |
|---|---|
| `Review_ID` | идентификатор отзыва |
| `Rating` | оценка пользователя |
| `Year_Month` | год и месяц публикации отзыва |
| `Reviewer_Location` | страна или регион автора отзыва |
| `Review_Text` | текст отзыва |
| `Branch` | филиал Disneyland |

## Описание результата
Пример структуры результата:

```json
{

  "api_provider": "Google Gemini API",
  "input_file": "data/DisneylandReviews.csv",
  "model": "gemini-2.5-flash-lite",
  "items_count": 5,
  "results": [
    {
      "review_id": 670772142,
      "sentiment": "positive",

      "short_summary": "Автор положительно оценивает Disneyland Hong Kong, отмечает знакомую атмосферу парка и интересные аттракционы.",
      "keywords": [

        "аттракционы",
        "очереди",
        "положительный опыт"
      ],
      "confidence": 0.9

```

## Основная логика работы
1. Загружает переменные окружения из файла `.env`.
2. Считывает CSV-файл с отзывами.
3. Ограничивает количество строк через параметр `--limit`.
4. Делит отзывы на пакеты через параметр `--batch-size`.
5. Отправляет каждый пакет отзывов в Gemini API.
6. Получает структурированный JSON-ответ.
7. Объединяет результаты всех запросов.
8. Сохраняет итоговый JSON-файл в папку `results`.

## Установка зависимостей
Перед запуском необходимо установить библиотеки:
```bash
pip install -r requirements.txt
```

## Запуск проекта
Пример запуска для обработки 10 отзывов пакетами по 2:
```bash
python src/llm_review_pl.py --input data/DisneylandReviews.csv --output results/reviews_analysis.json --limit 10 --batch-size 2
```
После успешного выполнения появится сообщение:
```text
Готово. Результат сохранен в файл: results/reviews_analysis.json
```
